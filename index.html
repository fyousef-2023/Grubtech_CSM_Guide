عميل جديد: ليس له حساب في رواء مسبقاً — يحتاج ملف بيانات فارغ تُرسله له لتعبئته كاملاً.
خطوات التعامل مع عميل جديد
  • ١
    تأكد من وجود Deal واشتراك
    سواء العميل تواصل معك وطلب الخدمة، أو اشترك مباشرة — في الحالتين لازم يكون في Deal واشتراك. أنت إما ترفع الـ Deal أو يكون مرفوعاً له. تحقق من وجود Account Setup Data Upload نوعه Grubtech Onboarding في CRM.
    Account Setup Data Upload → Grubtech Onboarding
    [ Invoices في CRM ]
    مثال: ظهور منتج الربط في Invoiced Items يعني أن العميل مشترك ✓
  • ٢
    أرسل للعميل ملف البيانات الفارغ
    أرسل له ملف الإكسل الخاص بتطبيقات التوصيل — يحتوي على صفحة Store ID وصفحة المنيو وصفحة الإضافات. اشرح له طريقة التعبئة.
    📋 قالب ملف المنتجات ▶ فيديو: شرح الملف
  • ٣
    اطلب Store ID لكل تطبيق — وساعد العميل إذا احتاج
    اطلب من العميل رقم الـ Store ID لكل تطبيق توصيل مشترك فيه. إذا ما عرف كيف يستخرجه، تابع معه مباشرة — الخطوات بسيطة وكلها موضحة في الفيديو التعليمي لكل التطبيقات.
    مثال — HungerStation: يسجل دخول ← يفتح Dashboard ← يضغط على Outlets — الـ Branch ID يظهر بجانب اسم كل فرع بين قوسين.
    [ Store ID في HungerStation ]
    ▶ فيديو: استخراج Store ID لكل التطبيقات
  • ٤
    استلم الملف وتحقق منه
    عند استلام الملف من العميل تحقق من:
    ✓ Store ID لكل تطبيق مشترك فيه ✓ صور المنتجات — إلزامية، العميل يرفعها على Drive. الموظف لا يشتغل عليها. ✓ اسم المنتج عربي وإنجليزي ✓ أسعار كل تطبيق — العميل حر يحدد سعره ✓ السعرات الحرارية (HungerStation فقط)
  • ٥
    سلّم الملف لـ Products Onboarding (فريق سعد)
    بعد التحقق من الملف وأنه مكتمل، أرسله لـ Products Onboarding عبر Account Setup Data Upload الموجود في CRM.

    مهم: لا تُبلغ فريق سعد قبل أن يُفتح الـ Account Setup Data Upload تلقائياً — هذا الفتح هو إشارة البدء.
    Products Onboarding يرفع التيكت لـ Grubtech
  • ٦
    تابع حتى اكتمال التفعيل
    تابع مع Products Onboarding (فريق سعد) والعميل حتى يتأكد اكتمال التفعيل.
    ✓ لا تغلق الـ Sub-stage إلا بعد التأكيد
عميل حالي: عنده حساب في رواء ومنتجاته موجودة على المنصة — Products Onboarding (فريق سعد) يُصدّر له ملف المنتجات جاهزاً، وما يحتاج يعبّئه من الصفر.
عميل جديد
  • ملف فارغ تُرسله للعميل
  • يعبئ المنتجات والأسعار من الصفر
  • يعبئ Store ID بنفسه
  • يرسل الصور والأسعار كلها
عميل حالي في رواء
  • Products Onboarding (فريق سعد) يُصدّر ملف المنتجات الجاهز
  • العميل يكمل الصور والأسعار فقط
  • يعبئ Store ID بنفسه
  • يراجع ويضيف أسعار التطبيقات
خطوات التعامل مع عميل حالي
  • ١
    تواصل مع العميل وأبلغه بالخطوة
    أبلغه أننا بنحتاج بياناته لربط تطبيقات التوصيل وأن عملية الإعداد ستبدأ قريباً.
  • ٢
    اطلب من فريق سعد ملف المنتجات
    Products Onboarding (فريق سعد) يُصدّر من CRM ملف المنتجات المضافة على منصة رواء — هذا الملف هو الأساس.
    تواصل مع Products Onboarding بـ Data Collection Number الخاص بالعميل
  • ٣
    أرسل الملف للعميل لإكماله
    الملف يحتوي المنتجات جاهزة — العميل يضيف فقط: الصور لكل منتج، أسعار بيع كل تطبيق توصيل، وStore ID لكل تطبيق.
    ▶ فيديو: كيف يستخرج العميل الـ Store ID
  • ٤
    استلم الملف المكتمل وتحقق منه
    تأكد من وجود الصور، أسعار التطبيقات مقارنة بأسعار رواء، وStore ID لكل تطبيق مشترك فيه.
  • ٥
    سلّم الملف لفريق سعد
    Products Onboarding (فريق سعد) يرفع التيكت لـ Grubtech ويتابع معهم.
    Products Onboarding يرفع التيكت لـ Grubtech
تنبيه: الملف غير مكتمل = Products Onboarding لا يرفع التيكت. تأكد من اكتمال كل الحقول الإلزامية قبل التسليم.
